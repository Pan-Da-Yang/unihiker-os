# 行空板 OS · 软件全家桶

为 **行空板 (Unihiker)** 打造的极简桌面操作系统套件，纯 Python + tkinter 实现，
直接跑在板载 2.8" 触摸彩屏上，也能在电脑（Windows / Linux / macOS）上开发调试。

包含四大模块：

| 模块 | 文件 | 功能 |
|------|------|------|
| 桌面启动器 | `main.py` | 图标桌面 + 任务栏时钟，一键启动各 App；设置面板可切换亮/暗主题、退出程序 |
| 文件管理器 | `filemanager.py` | 目录浏览、返回/上级、文件列表、删除、按类型联动打开、**一键运行 Python / Shell 脚本** |
| 图片查看器 | `imageviewer.py` | 自适应缩放、上/下张、放大缩小、旋转 |
| 视频播放器 | `videoplayer.py` | OpenCV 逐帧渲染、播放/暂停/停止、进度拖动 |
| 游戏中心 | `gamecenter.py` | 内置 28 个纯 tkinter 小游戏（2048、贪吃蛇、俄罗斯方块、扫雷、井字棋、四子棋、记忆翻牌、数字华容道、推箱子、四宫数独、走迷宫、猜单词、打地鼠、见色说字、反应速度、记忆顺序、猜数字、石头剪刀布、21点、掷骰子、幸运转盘、速算挑战、比大小、打砖块、弹球对战、接水果、打飞机、生命游戏），适配 240x320 触摸 + 键盘 |
| 引脚控制 | `pincontrol.py` | P0–P20 共 21 个引脚：每个可切换「读取模式」(数字输入) /「控制模式」(数字输出)；P0 为扩展板蜂鸣器引脚，单独提供蜂鸣器控制台（频率/时长/持续音/播放/停止/预设音名）；带滚动列表、读值轮询、板载 A 键返回 |
| 自制控制台 | `shconsole.py` | 在 tk 窗口内运行 `.sh`/`.bash` 脚本：实时输出、可交互输入、可停止（伪终端模式） |

## 运行

```bash
# 1. 安装依赖（行空板 / 开发机通用）
pip install -r requirements.txt

# 2. 启动桌面（行空板触摸屏务必用 --board）
python main.py --board      # 240x320 去边框、竖排、无 emoji
python main.py --full       # 保留窗口装饰的全屏（VNC/电脑调试）
python main.py              # 开发机窗口模式
```

也可以单独运行某个 App（同样需要 `--board` 时从 main.py 进入）：

```bash
python filemanager.py
python imageviewer.py  /path/to/photo.jpg
python videoplayer.py  /path/to/movie.mp4
```

## 行空板小屏适配说明

之前版本在 240×320 屏幕上出现：窗口边框还在、emoji 图标显示成空框、文字被截断。
现已新增 `--board` 模式，自动做以下调整：

- `overrideredirect(True)` 去掉标题栏和窗口边框，强制 `240x320+0+0`
- 彻底移除所有 emoji/特殊符号，改用 **Canvas 绘制图标 + 中文文字**
- 桌面图标改为 **3 列网格（2 行）**，共 5 个入口：文件管理、图片查看、视频播放、游戏中心、引脚控制；设置入口移到**右上角的小齿轮按钮**（带 `SURFACE` 背景块 + 白色齿轮，确保在 240×320 小屏上可见）
- 字号、间距、按钮全部压缩
- 文件管理器、图片查看器、视频播放器都按小屏重新布局
- 文件管理器顶部固定显示「返回」等按钮；路径框另起一行，避免按钮被挤出屏幕
- 文件管理器列表右侧加了**显眼的 tk.Scrollbar 滚动条**（宽度 18、蓝绿色滑块、深色槽），方便手指拖动查看深层文件
- 所有 App（文件管理、图片查看、视频播放、游戏中心）均支持按**行空板板载 A 物理键**（pinpong `button_a` 中断回调）返回桌面；开发机无硬件会自动跳过，键盘 A 仅作本地调试
- 所有 App 顶部均有显式的「返回」按钮，可关闭当前 App 回到桌面

所以行空板上请用：

```bash
python main.py --board
```

## 排错：图片 / 视频打不开

这两个 App 都依赖第三方库，若打开后**黑屏/空白/像“没反应”**，通常是以下原因之一：

1. **依赖没装**：图片需要 `Pillow`、视频需要 `Pillow + opencv-python-headless`。
   先装依赖再运行：

   ```bash
   pip install -r requirements.txt
   ```

2. **窗口开在了底层**：行空板没有窗口管理器，所有 App 都是 `overrideredirect` 且铺在 `240x320+0+0`。
   现已为图片/视频窗口加上单窗口 `spawn_window` 模式（自动隐藏桌面、关闭时恢复），
   并在初始化时捕获所有异常——任何打开失败都会弹「打开失败」提示框，不会再“静默没反应”。

3. **缺少依赖时的表现**：窗口仍会打开，只是显示「未安装 Pillow」「缺少 OpenCV / Pillow」等提示。
   看到这类提示就按第 1 条装依赖即可。游戏中心为纯 tkinter 实现，不依赖任何第三方库。

## 主题（亮色 / 暗色）

桌面第 4 格为「设置」，点开后可在「外观主题」里切换：

- **亮色**：浅色背景，适合光线充足的环境
- **暗色**：深色背景（默认），护眼、省电

选择会写入工作目录下的 `.unihiker_theme` 并持久化，下次启动自动应用。
切换主题后桌面会**自动重启**以让全部组件（含已打开窗口）套用新主题。
设置面板里还有「音量」滑块（0-100，持久化到 `.unihiker_volume`，预留给后续音频类功能）。
游戏中心为纯 tkinter 小游戏，不发声。
和「退出程序」按钮，可直接关闭整个 OS。

## 联动逻辑

- 文件管理器双击图片 → 图片查看器（并载入同目录所有图片）
- 文件管理器双击视频 → 视频播放器
- 文件管理器双击 `.py` 文件 → 弹出运行窗口：后台启动子进程，实时显示 stdout/stderr，可随时「停止」；也可选中 `.py` 后点底部「运行」按钮
- 文件管理器双击 `.sh` / `.bash` 文件 → 弹出打开确认窗口，提供三种动作：
  - **原生控制台**：调用系统终端模拟器（行空板上为 `lxterminal`，开发机自动探测 `gnome-terminal`/`konsole`/`xterm`/`Windows Terminal` 等）真实运行脚本，**适合需要全屏交互/TUI 的脚本**
  - **自制控制台**：用 `shconsole.py` 的 tk 窗口运行，实时回显输出、底部输入框可向脚本发送一行（类 Unix 用伪终端 pty，能驱动 `read`/菜单等交互式脚本；Windows 无 pty 则退化为只读输出），可随时「停止」
  - **编辑**：在文本编辑器里修改脚本源码
  - 选中 `.sh` 后点底部「运行」按钮，同样会进入该确认窗口
- 桌面图标可直接启动任一 App
- 桌面「游戏中心」进入 `gamecenter.py`，内置 28 个纯 tkinter 小游戏（2048、贪吃蛇、俄罗斯方块、扫雷、井字棋、四子棋、记忆翻牌、数字华容道、推箱子、四宫数独、走迷宫、猜单词、打地鼠、见色说字、反应速度、记忆顺序、猜数字、石头剪刀布、21点、掷骰子、幸运转盘、速算挑战、比大小、打砖块、弹球对战、接水果、打飞机、生命游戏），按「返回」回到游戏列表

## 快捷键

图片查看器：`←/→` 切换，`+/-` 缩放，`R` 旋转，`Esc` 关闭
视频播放器：`空格` 播放/暂停，`Esc` 关闭

## 关于声音

视频播放器只渲染画面、不输出声音——行空板默认无声环境更稳。
如需声音，可在 `videoplayer.py` 里接入 `pygame.mixer` 播放音轨。

## 自制软键盘输入法

文件管理器的**路径输入框点击即弹出自制软键盘**（`softkeyboard.py`），板子无实体键盘也能输入中文路径：

- **QWERTY 矩阵键盘**：参考手机/QQ 行空板键盘，使用 `grid` 等分布局，确保 240 宽小屏上所有按键真实可见
- **中文层**：输入拼音字母（如 `ni`），自动从 `pinyin_dict.json`（**1177 个常用汉字**拼音字库）过滤出候选字，点候选字即上屏；候选可翻页（‹ ›）
- **英文层**：直接输入 a–z，支持 `⇧` 大小写切换
- **符号层**：路径常用 `/ . - _ 0-9 : ~` 等（点 `123` 切换）
- 控制行：`中/英` 切换、`空格`、退格 `←`、`完成`（写回输入框）、`取消`
- 字库生成脚本 `gen_dict.py`（开发机用 pypinyin 生成 `pinyin_dict.json`，板子运行时只读 JSON，无需联网）

## 引脚控制

`pincontrol.py` 通过 pinpong 驱动行空板（扩展板）GPIO：

- **引脚列表 P0–P20**：每点「未用」按钮在 `未用 → 读取 → 控制 → 未用` 间循环。
  - 读取模式：引脚设为数字输入，界面每 500ms 轮询一次，显示「高 / 低」。
  - 控制模式：引脚设为数字输出，点「开 / 关」切换 `write_digital(1/0)`。
  - 「全部释放」把所有引脚切回未用（输入）状态，安全收尾。
- **蜂鸣器 (P0)**：P0 是扩展板蜂鸣器引脚，单独提供控制台——
  - 频率 50–4000 Hz（±20 步进）、时长 0.1–10 s（±0.1 步进）、「持续」勾选则无限鸣响；
  - 「播放 / 停止」、8 个预设音名（Do–Si / C5）一键试听；引脚列表里的 P0 也带一个「蜂鸣器」快捷按钮。
- 板载 **A 键**或顶部「返回」均可退出回到桌面；无 pinpong / 无硬件（开发机）时自动降级，界面照常打开并提示「无硬件」，不会崩溃。

> 注：P0 已固定用作蜂鸣器 PWM 通道，故不参与通用读/写切换；如确需把 P0 当普通数字脚用，把 `_make_pin_row` 里 `idx == 0` 的蜂鸣器分支改掉即可。

## 目录结构

```
unihiker_os/
├── main.py          # 桌面启动器（入口）
├── filemanager.py   # 文件管理器
├── imageviewer.py   # 图片查看器
├── videoplayer.py   # 视频播放器
├── gamecenter.py    # 游戏中心（内置 28 个小游戏）
├── pincontrol.py    # 引脚控制（P0–P20 读/写 + P0 蜂鸣器）
├── shconsole.py     # 自制控制台（运行 .sh/.bash，pty 实时输出 + 交互输入）
├── softkeyboard.py  # 自制软键盘输入法（中/英/符号）
├── pinyin_dict.json # 1000+ 常用汉字拼音字库（运行时读取）
├── gen_dict.py      # 字库生成脚本（开发机运行，需 pypinyin）
├── theme.py         # 统一样式 + 小屏模式开关
├── requirements.txt
└── README.md
```
