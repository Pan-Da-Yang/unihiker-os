# 行空板版 QQ（真·联机版）

一个跑在 **DFRobot 行空板（Unihiker）** 上的仿 QQ 聊天软件，纯 Python + tkinter，
屏幕逻辑尺寸 240×320，正好铺满行空板那块 2.8 寸触屏。

这一版是**真正的联机 QQ**：

- PC 上跑一个**零依赖服务器**（`server.py`，只用 Python 标准库，TCP + JSON 行协议）；
- 行空板和 PC 连到**同一个局域网**，各自作为客户端接入；
- 带**注册 / 登录**（密码 sha256+salt，登录下发 token 会话）；
- 带**好友码系统**（每人一个 6 位码，**发申请 → 对方接受**才成为好友）；
- 带**待接受好友申请**列表（「＋」菜单里查看/接受/拒绝）；
- 带**创建群聊**（按好友码邀请成员，群消息广播）；
- 消息**在线实时推送**，对方不在线时**离线存储**，下次登录自动同步历史；
- 内置 **QQ小助手** 机器人，注册即自动成为好友，可关键词应答；
- 屏幕键盘内置**拼音中文输入法**（中/EN 切换 + 候选条），不用外接输入法。

## 目录结构

```
qq_unihiker/
├── server.py         # PC 端服务器（零依赖，TCP+JSON，监听 0.0.0.0:8888）
├── net.py            # 客户端网络层（后台收消息线程 + 自动附 token）
├── ui.py             # tkinter 界面：登录/联系人/聊天/菜单/加好友/建群 + 屏幕键盘 + 拼音输入法
├── main.py           # 入口，自动识别 PC（小窗）/ 行空板（全屏），记住服务器 IP
├── pinyin.json       # 离线拼音字典（拼音 -> 汉字候选）
├── gen_pinyin.py     # 生成 pinyin.json 的脚本（已生成好，一般不用重跑）
├── users.json        # 服务器数据（自动创建/更新，只有机器人是初始数据）
├── config.json       # 客户端记住的服务器 IP（首次连接后自动生成）
└── selftest_full.py  # 端到端自测脚本（注册->加好友->建群->私聊->群聊->机器人->离线消息）
```

## 一、在 PC 上启动服务器

需要 Python 3（标准库即可，无需 pip 安装任何东西）：

```bash
cd qq_unihiker
python server.py
```

启动后会打印：

```
QQ 服务器已启动，监听 0.0.0.0:8888
板子端连接时填本机局域网 IP（用 ipconfig / ifconfig 查）
```

**查一下本机局域网 IP**（板子要填这个）：

- Windows：`ipconfig` 看「IPv4 地址」（一般是 `192.168.x.x`）
- macOS / Linux：`ifconfig` 或 `ip a` 看 `inet`

> 服务器数据存在同目录的 `users.json`，重启不丢。想彻底清空就删掉 `users.json` 再启动（会只剩 QQ小助手）。

---

## 二、在行空板上跑客户端

把整个 `qq_unihiker` 文件夹拷到板子（`/root/qq_unihiker/` 即可），用 WebIDE 上传 /
FileZilla(SFTP) / 物理 U 盘都行。然后在行空板终端：

```bash
cd /root/qq_unihiker
python3 main.py
```

程序自动识别行空板，**全屏**铺满触屏。

**首次连接**：登录页多了一个「服务器IP」输入框，默认已填 `win1q4t1r.xyz`，
（如果服务器在别的地址，改成对应 IP 或 `IP:端口` 格式，例如 `192.168.1.11:8888`）。
然后「注册新账号」或「登录」。连接成功后 IP 会记到 `config.json`，以后自动重连。
断网时登录页会出现「重试连接」按钮。

> 在 PC 上预览界面：`python main.py`（弹 240×320 小窗，可直接用物理键盘输入，回车发送）。

## 三、怎么用

1. **注册**：填用户名 + 密码，点「注册新账号」。注册成功会自动登录，并分配一个
   6 位**好友码**（点「＋」→「我的好友码」可随时查看，发给对方）。
2. **加好友（发申请）**：点右上角「＋」→「添加好友」→ 输入对方好友码 →「确定」。
   这时只是**发出申请**，对方会在「＋」→「待接受的好友申请」里看到你，点「接受」后双方才成为好友。
3. **待接受的好友申请**：「＋」菜单里这一项带未读数量徽标（`待接受的好友申请 (2)`）。
   点进去每个申请有「接受 / 拒绝」两个按钮。
4. **建群**：「＋」→「创建群聊」→ 填群名 + 成员好友码（多个用逗号分隔）→「创建」。
4. **聊天**：点联系人/群进入聊天页。屏幕键盘点「中/EN」切到中文，输入拼音后
   下方候选条选字（空格提交第一个，点候选字直接上屏）。
5. **机器人**：QQ小助手注册即自动成为好友，发「你好 / 几点 / 天气 / 在吗」会答你。

## 四、自测（可选）

服务器在运行时，另开一个终端跑端到端自测：

```bash
python selftest_full.py
```

会依次验证：注册、发好友申请、对方接受、双方互成好友、建群、私聊实时推送、群聊广播、
机器人回复、离线消息历史同步。全部通过会打印 `18/18 通过`。

## 说明 / 踩坑

- **输入法**：屏幕键盘自带拼音输入法，离线、零依赖，不依赖系统输入法框架。
- **emoji**：行空板自带的老版 Tcl/Tk 不支持 U+10000 以上的彩色 emoji（会 `TclError`），
  所以界面用的 `＋ ‹ ⇧ ⌫` 等都是 BMP 平面的普通符号，避开这个坑。
- **改端口**：默认 8888，改 `server.py` 顶部 `PORT` 和 `main.py` 的 `PORT` 即可。
- **想接真实大模型**：把 `server.py` 里 `bot_reply()` 改成调用你的 LLM API，
  QQ小助手就能真对话。
